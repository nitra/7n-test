## Огляд

Файл виконує повне вимірювання покриття коду за допомогою Vitest у єдиному проході. Він повертає дані про покриття для кожного файлу, а також список тестів, які не пройшли. Це забезпечує можливість контролю за рівнем тестового покриття окремих частин кодової бази. Додаткові можливості дозволяють виявляти файли вихідного коду та визначати ті, що не відповідають встановленим вимогам покриття. Для коректної роботи коду необхідна конфігурація у файлі test-results.json.

## Поведінка

Поведінка
measureCoveragePerFile запускає Vitest з генерацією покриття та звітністю у форматі JSON у єдиному проході, повертаючи дані про покриття по файлах та список тестів, що не пройшли. При цьому ігноруються папки та файли, такі як node_modules та .git, і винятки у процесі вимірювання обробляються, не викликаючи збоїв.
getUncoveredFiles відфільтровує файли, покриття яких нижче заданого порогового значення.
findSourceFiles рекурсивно знаходить усі файли вихідного коду в заданому каталозі, виключаючи тестові файли та директорії, визначені як ігнорувані.

## Публічний API

- measureCoveragePerFile — Вимірює покриття коду за файлами, збираючи результати покриття Vitest та логуючи провалені тести за один прохід.
- getUncoveredFiles — Повертає список файлів, які не досягли встановленого порогу покриття.
- findSourceFiles — Рекурсивно шукає файли вихідного коду в директорії, ігноруючи тестові файли та проігноровані каталоги, використовуючи це для ініціалізації у разі відсутності даних про покриття.

## Гарантії поведінки

- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- Кешує результати в межах одного прогону.
- Свідомо пропускає шляхи: `.git`, `node_modules`.
