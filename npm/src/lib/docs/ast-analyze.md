## Огляд

Цей модуль виконує статичний аналіз файлів JS/ESM за допомогою oxc. Він витягує точні рядки `vi.mock` та відповідні форми (shapes) на основі використання імпорту, зіставляє експортовані та внутрішні символи, визначає побічні ефекти, читання змінних середовища (`process.env`/`env.KEY`) та використання `fetch` у коді.

## Поведінка

1. Викликає функцію analyzeModule для аналізу коду.
2. Парсить вхідний код за допомогою rollup/parseAst. У разі помилки парсингу повертає структуру з порожніми значеннями для всіх полів.
3. Визначає прив'язки імпортів, зіставляючи їх з зовнішніми пакетами.
4. Для кожної прив'язки аналізує всі шляхи використання, щоб побудувати структуру заглушки (mock shape).
5. Формує список `externalMocks` у вигляді рядків `vi.mock` на основі виявлених заглушок.
6. Сканує тіло коду, щоб зібрати назви всіх символів, які явно експортуються.
7. Сканує тіло коду, щоб зібрати назви усіх оголошень верхнього рівня (змінних чи функцій), які не є експортованими.
8. Перевіряє наявність виразів виклику на верхньому рівні, щоб визначити, чи є у модулі побічні ефекти.
9. Збирає всі ключі, які зчитуються з середовища (`env` або `process.env`).
10. Перевіряє вихідний код на наявність викликів `fetch`.
11. Повертає об'єкт, що містить результати: `externalMocks`, `exportedNames`, `internalNames`, `hasSideEffects`, `envReads`, та `usesFetch`.

## Публічний API

analyzeModule — аналізує вихідний код ESM та повертає структуровану інформацію для створення тестів.

externalMocks — масив об'єктів, що містить необхідні моки для зовнішніх пакетів, включаючи сам рядок моку.
exportedNames — список назв, які експортуються із модуля.
internalNames — список внутрішніх (неекспортованих) назв елементів у модулі.
hasSideEffects — булеве значення, що вказує на наявність побічних ефектів у модулі.
envReads — список змінних середовища, які зчитує модуль.
usesFetch — булеве значення, що вказує на використання функції `fetch` у модулі.
