## Огляд

Файл проводить runtime probing експортованих функцій через чотири стратегії: `probeModule` викликає кожен експорт з граничними примітивами для отримання фактичних вихідних даних; `probeFetchCalls` перехоплює глобальні HTTP-запити, щоб фіксувати реальні URL та ініціалізацію для кожного експорту; `probeTimeVariants` запускає кожен експорт у фіксовані часові вікна ([0,9,14,22]) для виявлення чутливих до часу змін; а `probeHelpers` витягує неекспортовані допоміжні функції з вихідного коду для визначення їхніх фактичних форм виходу. Усі стратегії мають принцип best-effort: у разі будь-якої помилки вони повертають порожнє значення, не викидаючи винятків. Функціонал не залежить від кешування.

## Поведінка

Поведінка:
probeModule викликає кожен експортований функціонал з граничними примітивами, щоб визначити фактичні вихідні дані.
probeFetchCalls перехоплює глобальний запит `fetch` та збирає реальні URL та ініціалізацію для кожного експортованого функціоналу.
probeTimeVariants виконує кожен експортований функціонал у різні години доби та доповідає про ті, чий вихід залежить від часу.
probeHelpers витягує внутрішні допоміжні функції з коду та викликає їх з загальними комбінаціями параметрів для виявлення фактичних форм виходу.

## Публічний API

probeModule — Виявляє функції, експортовані модулем, за допомогою їх запуску в дочірньому процесі.
probeFetchCalls — Перехоплює глобальний виклик `fetch` і виконує кожну експортовану асинхронну функцію з різними аргументами, щоб фіксувати фактичний URL та ініціалізацію, які вона конструює.
probeTimeVariants — Запускає кожну експортовану функцію у різний час доби. Повідомляє про функції, чий результат змінюється залежно від години.
probeHelpers — Витягує неекспортовані допоміжні функції з вихідного коду та викликає їх із загальними комбінаціями параметрів, щоб модель штучного інтелекту бачила фактичну форму виводу замість припущення.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- За певних помилок повертає порожнє значення (напр. `null`) замість винятку.
