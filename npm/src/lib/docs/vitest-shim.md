## Огляд

Цей файл надає спільні утиліти для тестування на основі Vitest. Він дозволяє виконувати тести у цільових проектах, де Vitest не встановлений локально, оскільки використовується Vitest, вбудований у `@7n/test`. Механізм конфігурації (залежить від `package.json`) забезпечує обхід будь-яких помилок завантаження конфігурації у цільовому проекті. Публічні функції включають `VITEST_BIN`, `VITEST_SHIM_CONFIG` та `ensureVitestShim`.

## Поведінка

VITEST_BIN — Абсолютний шлях до вбудованого виконуваного файлу Vitest.
VITEST_SHIM_CONFIG — Абсолютний шлях до тимчасового файлу конфігурації Vitest, що забезпечує роботу збірки без встановлення Vitest у цільовому проекті.
ensureVitestShim — Гарантує існування файлу конфігурації Vitest, записуючи мінімальний конфіг у тимчасову директорію, ігноруючи шляхи до `node_modules`.

## Публічний API

VITEST_BIN — Шлях до виконуваного файлу Vitest, скомпільованого для використання.
VITEST_SHIM_CONFIG — Мінімальна конфігурація Vitest, яку створюють у тимчасовій директорії ОС, щоб імпортований скомпільований Vitest міг отримати доступ до нього.
ensureVitestShim — Гарантує існування файлу конфігурації шиму (повторне виконання не змінює стан).

## Гарантії поведінки

- Свідомо пропускає шляхи: `node_modules`.
